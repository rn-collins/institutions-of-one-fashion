# Machine rings for the held social pieces

Nov 2, 2026, RN Collins studio. Each of the 88 held carousels has one real, openly licensed photo of an old machine in its ring (v3.19 frame). No machine is used twice, and none comes from the studio machine library. Carousel A, "the institutional sequence," gets a making machine (sewing, knitting, spinning, weaving, cameras, presses). Carousel B, "what the document changes," gets an office machine (typewriters, adding machines, sorters, readers, teleprinters, switchboards). Pins and the YouTube thumbnail use the carousel A machine; the Reel storyboard uses the carousel B machine. The ring frames the slide and is never evidence for the dossier.

Registry: `data/ring-machines.json`. Search log: `data/ring-machines-search-log.json`. Build check: `loadRingRegistry` in `scripts/render-assets.mjs` stops the build if a carousel has no machine, a machine is reused, a file hash changes or a licence is outside CC0, CC BY, public domain or U.S. government. Three B01 frames with very long museum credits drop the credit panel from 34 px to 30 px so the machine credit fits; `.production/qa/render-fit.json` lists them.
